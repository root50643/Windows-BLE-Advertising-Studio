# Changelog

## 1.0.0 - 2026-11-01

- Added seven-page WPF application with MVVM, themes and localization resources.
- Added Windows BLE adapter detection, asynchronous Publisher/Watcher control,
  honest capability reporting and explicitly marked mock mode.
- Added raw/structured hex editing, bounded scanning and RSSI history.
- Added versioned profiles/revisions, DPAPI vault, CSV/JSON and diagnostics.
- Added Apple OpenHaystack / Google FHN structural research and evidence reports.
- Added xUnit coverage, executable GUI smoke verification, Windows build/release
  workflows and self-contained single-file win-x64 packaging with SHA256.
- Documented unsupported network/accessory features and real-hardware boundaries.
- Added Traditional Chinese as the primary README, a linked English README,
  standalone EXE release assets and checksum filenames matching downloads.
